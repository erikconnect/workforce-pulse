## 🤖 AI Agents

Workforce Pulse uses specialized AI agents for development tasks:

- **Frontend Agent** - React, Next.js, TypeScript, Tailwind
- **Backend Agent** - Node.js, Express, MongoDB
- **Integration Agent** - External APIs & data scraping
- **Testing Agent** - Vitest, testing patterns
- **Documentation Agent** - Technical writing, docs
- **DevOps Agent** - Vercel deployment, CI/CD

See **[agents.md](agents.md)** for quick reference or **[getting-started/agents.md](getting-started/agents.md)** for detailed guide.

## 📋 Project Information

### Tech Stack
- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS 3
- **Backend:** Express.js, MongoDB (Mongoose)
- **Data Sources:** Bright Data, JobAps RSS, USAJOBS, ArcGIS
- **Testing:** Vitest, Playwright
- **Deployment:** Vercel

### Key Features
- 🚨 Critical workforce signals for Public Safety roles
- 📈 Skills demand tracking and trend analysis
- 🎯 Mission-based action planning
- 🤝 Community playbooks for workforce development
- 🗺️ Geospatial workforce visualization
- 🏛️ Montgomery-specific civic branding
